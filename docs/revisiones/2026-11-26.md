- Las rutas admin usan `requiereAuth`+`requiereRol('ADMIN')` sin

  admin invitado podría operar sin verificar.
- **Conflicto con tests bloqueados:** los tests de ediciones/empresas/alumnos/
  registro crean admins sin verificar y esperan 200/201; enforcar rompería esos
  tests bloqueados. → Documentado como aceptado; endurecer requeriría OK.

  Impacto bajo; criterio documentado. → Documentado en `plan-desarrollo.md`.
